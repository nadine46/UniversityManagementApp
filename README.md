# University Management App

A Java console application for managing university students, courses, and enrollments using PostgreSQL.

## Features
- Add, view, update, and remove students.
- Add, view, and remove courses.
- Enroll students in courses.
- Update enrollments.
- View student enrollments using JOIN.
- Handle input and database errors.

## Technologies
- Java
- JDBC
- PostgreSQL
- Git and GitHub
