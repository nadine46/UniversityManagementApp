# University Management App

A Java application for managing university students, courses, and records using PostgreSQL.

## Features
- Add, view, update, and remove students.
- Add, view, and remove courses.
- Enroll students in courses.
- Update student enrollments.
- View student enrollments using SQL JOIN.
- Handle input and database errors.

## Technologies
- Java
- JDBC
- PostgreSQL
- Git and GitHub

## Project Structure
- Lab1: Object-Oriented Programming.
- Lab2: Database connection and DAO classes.
- Lab3: Console-based management application.
